Student management system with GPA calculation and reports, built with Flask and SQL.

Features
Student, course and grade management: full CRUD operations with a normalized (3NF) relational database
Dual database support: works with SQLite and MySQL, with foreign key integrity, ACID transactions and cascading deletes
Automated GPA calculation: computes GPA on the 4.0 scale
Dean's Honor Roll: filters top-performing students automatically
One-click reports: export data to CSV and JSON
REST API: programmatic access to student, course and grade data
Two interfaces: a responsive web dashboard and a menu-driven command-line interface (CLI)
Secure by design: parameterized SQL queries and regex-based input validation to prevent SQL injection
